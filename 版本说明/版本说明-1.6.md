# 1.6 改动说明

相对 1.4，这一版把整套**主题系统**接上了：游客侧现在有 16 套主题可选，每套都能日 / 夜切换，并且可以单独设置背景、字体、缩放。改完之后也对界面各处做了一轮清理。

GitHub 的 `1.6主题` 分支是这一版的开发分支。

## 新增

- **16 套主题**  
  「主题」按钮点开后，下面一排可切换：默认 / 极简主义 / 新拟态 / 玻璃拟态 / 商务简约 / 渐变风格 / 孟菲斯 / 赛博朋克 / 瑞士风格 / 杂志排版 / 手绘插画 / 等距插画 / 复古怀旧 / 未来科技 / 温暖治愈 / 粗野主义。  
  选中的主题持久化到本地，下次打开继续生效。

- **日 / 夜模式独立切换**  
  主题面板左侧第二个图标（☀ / ☾）一键切换。  
  切换时不会丢主题，只会改这套主题下的「亮」或「暗」配色。

- **主题面板布局切换**  
  主题面板左侧第四个图标（↔ / ▦）：横向滑动还是换行展示，看主题多了的时候哪种顺手切哪种。

- **高级主题设置**（主题面板左侧第一个图标 ⚙）  
  单独一层弹窗，可以精细控制：
  - **字号 / UI 缩放**：百分比滑块；勾选「跟随系统」后跟随浏览器字号
  - **主题透明度**：把面板调得更透明或更厚
  - **文字遮罩**：把文字调得更清楚
  - **背景模糊 / 不透明度 / 暗化层**：调节自定义背景图
  - **字体源**：系统字体 / 主题默认 / 自定义链接（粘贴字体 URL + 名称即可加载）
  - **背景锁定 / 内容锁定**：锁住上面这些滑块，防止误触

- **自定义背景**
  - **上传图片**：选好图后在裁剪框里裁掉不要的部分，确认后设为背景
  - **粘贴 URL**：直接填图片链接
  - **清空**：一键回到无背景

- **悬浮提示（Toast）**  
  原来用浏览器原生 alert 的地方（复制成功、提交成功、错误提示等）全部换成顶部居中的小气泡，停留半秒 / 两秒半自动消失。  
  不挤布局、不打断操作。

## 优化

- **默认主题下所有面板视觉统一**  
  之前主题面板背景是漏的（用了不存在的 `--card-bg`），看上去像漂在页面外。  
  现在跟同一主题下的其他卡片、按钮完全一致：同一个圆角、同一种边框、同一种高亮色。

- **非默认主题对各组件的样式适配**  
  卡片、按钮、输入框、弹窗、标题、提示文字等，全部用主题自己的变量驱动背景 / 边框 / 圆角 / 阴影 / 字体。  
  之前某些主题下还残留默认主题的蓝色玻璃感，现在每套主题都是它自己的样子。

- **非默认主题下勾选框样式**  
  之前只有默认主题给勾选框定义了勾子的颜色。非默认主题现在也会跟随主题色（背景色 / 边框 / 勾子颜色一致），15 套主题里勾选框都看得清。

- **粗野主义夜间模式完整还原粗野风格**  
  黑底白字的粗野夜间下，整页（卡片、按钮、输入框、弹窗、主题面板、筛选栏）都改成黄底 + 黑边 + 粗硬阴影 + 黑字，跟粗野主义日间同源。  
  小剧场标题、主题切换按钮、复制提示都能看清。

- **渐变风格日间模式标题可读性**  
  渐变日间原本白字标题配半透明白卡，对比度几乎为零。现在改成深紫色，标题在卡片里清晰可见。

- **按钮边框毛刺修复**  
  圆角按钮上的 1px 半透明边框在切换主题 / 日夜时偶尔会闪一下。改成用 `box-shadow inset` + outline 兜底，圆角处不再有渲染抖动。

- **字体默认改为系统字体**  
  之前默认会自动加载主题自带的字体，可能与正文阅读体验冲突。现在默认用系统字体栈，启动更快、不浪费流量。  
  想要主题字体的话，去高级设置 → 字体源 → 主题默认。

- **老用户字体源一次性迁移**  
  之前打开过页面的用户会被识别为「想用主题字体」，现在只迁移一次，重置后跟随新默认「系统字体」，再手动改不会被覆盖。

- **上传页重构 + 投稿记录**  
  投稿页内部结构重写，单篇 / 批量 / 自动标题识别 / 历史昵称都更稳。  
  「我投过的小剧场」投稿记录可回填编辑、重新投稿、删除，或一键清空。

- **按钮尺寸 / 字体对齐**  
  顶部 nav 按钮（repo / 衍生 / 新增 / 广场 / 上传小剧场 / 主题）尺寸和字重统一。

- **iPad 判定修复**  
  之前 iPad 被误判为手机，「一行几个」只能选 2。现在 iPad 可以选到 3。

## 修复

- **小剧场标题在粗野夜间模式下看不见字**  
  之前白字叠白底（或黑字叠黑底），现在统一用粗野风格的黑边 / 黄边硬阴影，无论卡片底色是什么都能看清。

- **主题切换按钮（粗野夜间）字看不见**  
  「极简主义 / 新拟态 / 玻璃拟态…」等切换主题的小按钮，之前默认用深蓝灰字，叠在黑底上完全消失。现在统一为粗野夜间风格的硬朗配色。

- **复制按钮的复制提示在默认主题下不清晰**  
  日间下原本「深绿 + 浅绿」对比度差，看不清字。现在改成深绿字 + 浅绿底，且边框 / 阴影更明显。

- **更新提示弹窗按钮配色**  
  「稍后手动刷新 / 立即刷新」两个按钮在非默认主题下的配色跟随各主题自动调整。

- **CI / lint 修复**  
  顺手把上一轮留下的 `react-hooks/exhaustive-deps`、`prefer-const` 等 ESLint 警告清掉，并新增 Prettier 格式检查。本地推送前会自动跑 `lint → format:check → type-check → test → build`。

## 没改什么

- 数据库结构和已有的小剧场、repo 内容
- 审核后台的审核 / 删改 / 备份 / 标签管理逻辑
- 公共 API（投稿、刷新、点赞计数等接口签名不变）

## 已知问题 / 待办

- 字体加载面板里没有「下载到本地后再应用」的开关，依赖 CDN；网络差时首屏字体可能回退到系统字体。
- 主题切换的过渡动画在低端机上偶发掉帧，目前没做降级处理。
