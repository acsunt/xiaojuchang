# 1.3 改动说明

相对 1.2，这个版本主要改了游客广场：搜索更好用，并加了两套互不影响的折叠。GitHub 的 `1.3` 只做备份。

## 改了什么

- **广场搜索单独占一行**  
  搜索框从筛选区里挪出来，放到「列表操作」下面，整行独占。

- **搜索框下面可以点选字段**  
  可点：标题、作者、分类、正文。  
  没点选时，这几个字段都会搜。点选后，只搜选中的字段。  
  逻辑和审核后台的搜索一样。

- **分类和作者同时展开时加分隔线**  
  两个筛选列表都打开时，中间会有一条分隔线，看起来更清楚。

- **「随机」左边的折叠按钮还在**  
  这个按钮只收起搜索、时间排序、屏幕筛选等控制区。  
  不会收起随机、分类、导出那一行。

- **repo 左边新增折叠图标**  
  顶部导航里，repo 左边多了一个折叠按钮。  
  这个按钮只收起下面的工具栏：随机、分类、导出等。  
  不会把搜索和筛选一起收走。

- **两套折叠互不影响**  
  收起工具栏后，搜索和筛选区仍可单独显示。  
  点「随机」左边的折叠，也只会收起搜索和筛选。

## 没改什么

- 数据库数据和已有小剧场、repo 内容
- 审核后台、上传、衍生详情等其他功能
- GitHub 备份仍然不包含 `node_modules`、`dist`、`.wrangler` 和本机真实配置
